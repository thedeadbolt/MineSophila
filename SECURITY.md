# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately via
[GitHub private vulnerability reporting](https://github.com/thedeadbolt/MineSophila/security/advisories/new).

You can expect an acknowledgement within a week. Once a fix is ready, the advisory will be
published with credit to the reporter, unless you'd rather stay anonymous.

## Supported versions

The project is pre-1.0. Only the latest release of each package receives fixes.
