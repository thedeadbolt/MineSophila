| R7 information content (decision 10 check, 2026-10-25) | On three 1600×825 example frames (dusk hill, snowy forest, day meadow; 8-bit JPEG), R7's spread across valid ommatidia is 15–97× one 8-bit input step at the frame's mean level, so quantisation does not limit it there. But a linear fit on R1_6 and R8 predicts R7 with R² = 1.0000 for both pale and yellow in every frame. The reason is the spectra, not only that all channels are linear in RGB: the Rh3 and Rh4 visible tails overlap almost only the blue primary (catch rows Rh3 ≈ [1.9e-11, 7.2e-9, 8.1e-6], Rh4 ≈ [1.3e-9, 8.4e-7, 1.6e-3] for [R, G, B]), so R7 ≈ k · B_linear. Rh5 (pale R8) is also blue-dominated, so pale R7 is almost exactly predictable from R8: the relative residual of the pale R7 row against span(R1_6, R8) is 5.8e-5. For yellow (and dorsal yellow) the residual is 1.2% (1.16%), so R² = 1.0000 on these frames is scene-dependent. R7 adds no independent information in v0. Do not treat R7 or R7/R8 as a colour signal unless true UV input is added | measured (on example frames; residuals computed from the catch matrix) | example frames from the user | `spectral.py` (`SpectralModel.receptors`) |
